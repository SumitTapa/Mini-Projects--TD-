File Handling Utilities
Description
This repository contains two Python programs for basic file operations:
File Reader: Reads and displays text files with line numbers
File Writer/Appender: Handles writing, appending, and displaying file contents
These utilities demonstrate fundamental file I/O operations in Python with user-friendly interfaces.

File Reader Program
Features
Reads any text file specified by the user
Displays each line with proper line numbering
Handles file-not-found errors gracefully
Simple and straightforward interface

File Writer/Appender Program
Features
Writes new content to files
Appends content without losing existing data
Interactive prompts for user input
Displays final file contents
